# Decisions: one row per class of mistake

The classes a reviewer marked on a real promotion document, each turned into a rule with an
enforcer, and what changed. No names and no quotes. The dated, decision-by-decision log of the
review that produced these rows is [docs/decisions/2026-11-23-promo-doc-grill.md](docs/decisions/2026-11-23-promo-doc-grill.md).
The proof is [evals/results/2026-11-23-promo-doc.md](evals/results/2026-11-23-promo-doc.md): the
red fixture trips every row, the green one passes.
